The 81 numbers table (數理)

The stroke verdicts the name builder uses, all 81 of them

When the name builder scores a Chinese name, it adds up the stroke counts of the surname and the given name, as counted in the Kangxi Dictionary (康熙字典), into the Five Grids (五格). Each grid number is looked up in a table of 81 numbers, and the table says one thing about each number: auspicious or not. This page prints that table exactly as the engine holds it.

35 of the 81 numbers are marked auspicious (吉) and 46 are not. The verdicts follow a modern naming-school convention. The engine cites no classical text for them, and neither does this page.

How a name uses the table

The builder takes the Kangxi stroke count of each character and forms the five grids. The table below shows how each grid is formed for a one-character surname and a two-character given name, and how many of the 25 points the Five Grids carry each grid is worth. A grid scores its points when its number is auspicious and nothing otherwise.

GridHow it is formedPoints, two-character given namePoints, one-character given name
天格 Heaven gridThe surname strokes plus 1Not scoredNot scored
人格 Person gridThe surname strokes plus the first given-name character815
地格 Earth gridThe two given-name characters added together710
外格 Outer gridThe second given-name character plus 13Not scored
總格 Total gridAll three characters added together7Not scored

How the page stays true to the engine

Every row is produced by calling the engine function that the name builder calls for the same number, and a test regenerates the page from the engine.

The test fails if a single cell differs, so a change to the engine's verdicts cannot reach the page unnoticed.

What this table is not

  • Not a classical table. The auspicious set is a modern naming-school convention. The method page records it as a two-state scale, auspicious or not, until a cited finer table is adopted.
  • Not a finer reading. Some schools add a middle band, or attach a poem and a fortune to each number. The name builder uses neither, and this page does not publish them.
  • Not a verdict on a person. It judges a number. Five Grids carry 31.25 of the 100 points in a name score, and the other parts are described in the guide to how names are scored, not here.
  • Not tested against outcomes. Nothing links a verdict here to anything that happens to a person. The only check is that this page shows the list the engine uses.
  • Not open-ended. The table stops at 81. For a larger grid number, the engine subtracts 81 until the result is between 1 and 81.
