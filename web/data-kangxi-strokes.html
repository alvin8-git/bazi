Kangxi stroke counts for 3,500 common characters

The stroke table behind the name builder

Chinese name numerology counts strokes by the Kangxi Dictionary (康熙字典), and the dictionary counts the traditional form of each character. A simplified character is therefore counted as its traditional form: the name builder counts 华 as 華, with 14 strokes.

This page lists the Kangxi count for each of the 3,500 characters in the first level of the General Standard Chinese Characters (通用规范汉字表), the 2013 national list. The name builder offers these first and calls them common. 1,197 of them are counted as their traditional form, which is not the character in the list. 406 have another traditional form that the builder offers as a choice, and the table lists it.

How the counts are produced

Each count is derived from the traditional form of the character: the Kangxi radical at its full form plus the remaining strokes in the Unicode Unihan database, with one count set by hand.

  1. The engine takes the traditional form of the character. Where a simplified character has several traditional forms, the builder picks a default and offers the others, which is the last column.
  2. It counts the Kangxi radical at its full form, and adds the remaining strokes recorded in the Unicode Unihan database for that traditional character. A radical written in a shortened form is still counted in full, for example 氵 as 水 with 4 strokes.
  3. One count is set by hand. 萬 is 15 strokes, because the first radical listing in the Unicode data is not the Kangxi one for that character.

Every row is read straight from the engine's character data. A test regenerates this page from it and fails if a single cell differs.

What this table is not

  • Not a copy of the printed dictionary. The counts are derived by rule, not looked up page by page.
  • Checked on 42 characters only. The rule reproduces 42 counts pinned in the engine's tests, 28 common surnames and 14 given-name characters, taken from published stroke tables. The other 3,458 characters have no independent check on this page.
  • Not the only way to count. Modern stroke counts, and some schools' counts, differ from the Kangxi count for many characters. A different count changes the grid numbers of a name.
  • Not a list of good name characters. It lists a stroke count for every common character, whatever its meaning or sound.
