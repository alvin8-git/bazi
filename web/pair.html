How to read this

The score starts at 50. Each comparison adds or removes points, and the table adds up to the total. It always stays between 5 and 95.

  • The score working: one row per factor, with its points.
  • How they see each other: the role each person plays for the other, using the Ten Gods (十神).
  • Where the charts touch: each part of one chart compared with each part of the other.
  • Three ways to read it: the same score seen as family, as a couple, and as colleagues.

This is a traditional reading, not a prediction.
