How to read this

The score runs from 5 to 95 and starts at 50. Each comparison adds or removes points, and the table sums exactly to the total.

  • Component table: one row per factor, drawn against its own range.
  • How they see each other: the Ten Gods (十神) each person is to the other.
  • Pillar interactions: every branch of one chart set against every branch of the other.
  • Three framings: the same score read for family, couple and colleagues.

This is a traditional reading, not a prediction. Every number cites the classical rule behind it.
